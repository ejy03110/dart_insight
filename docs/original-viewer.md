# 최신 공시 본문 열람과 목록 복귀

최근 공시 상세에서 **공시 본문 불러오기**를 눌러 실제 원문을 읽는다. 상세 화면 진입·필터 변경·
목록 복귀만으로 원문 다운로드나 AI 분석을 실행하지 않는다. 기존 DART_API_KEY 설정을 재사용한다.

## 원문 조회와 지원 범위

- 기존 DartClient의 `document.xml` 요청 경로와 TLS·timeout·제한 재시도·요청 간격을 재사용한다.
  기존 OpenDartSource.collect는 RAG용 평문 수집과 진단 ZIP 저장을 포함하므로 호출하지 않는다.
  새 독립 서비스가 기존 `_decode_xml`/`_xml_text`의 엄격한 파싱·제한적인 문자 보정을 재사용한다.
- ZIP 안의 `.xml`, `.html`, `.htm` 및 직접 XML/HTML 응답을 지원한다. UTF-8·EUC-KR·CP949와
  기존 파서가 허용하는 XML 선언/BOM의 UTF-16/32를 처리한다. 잘못된 중첩 구조나 알 수 없는
  엔티티를 임의로 복구하거나, 일부 파일만 성공한 내용을 전체 본문으로 표시하지 않는다.
- 구조가 안전하게 해석되면 제목·문단·표를 표시한다. 표의 수치와 셀 병합 값을 보존하고,
  원본 JavaScript·스타일·임의 속성/외부 리소스는 실행하지 않는다. 허용된 태그만 새로 구성하고
  텍스트를 escape한다. 원문 HTML을 그대로 삽입하지 않는다.
- 문자 보정이 필요하거나 사용자 정의 표 구조/깊은 구조 등으로 배치를 안전하게 재현하지 못하면
  기존 파서가 검증한 **전체 텍스트**로 표시하고 배치 재현 한계를 안내한다. 내용 요약/잘라내기는 하지 않는다.
- PDF·이미지·첨부파일 자체 렌더링, 암호화/손상된 ZIP, 지원하지 않는 인코딩/HTML 구조는
  지원하지 않는다. ZIP의 표시 가능한 문서와 다른 첨부가 섞였으면 첨부 제외를 안내한다.
  OpenDART가 원문을 제공하지 않는 공시(`014`)도 공식 DART 링크로 확인한다.
  공시 유형 A~J 전체에 본문이 제공된다고 보장하지 않는다.
- 압축/해제 크기는 기존 100 MiB, 문서 파일은 최대 1,000개로 제한한다. ZIP은 메모리에서만 읽고
  파일 경로로 추출하지 않는다. 서비스 캐시는 최대 20건/본문+HTML 32 MiB(LRU)이므로
  단일 표시 결과가 그 한도를 넘으면 부분 표시 대신 공식 원문 확인을 안내한다.
- 성공 결과는 최대 1시간 재사용하고 실패/빈 본문/미지원 결과는 1분 재시도 대기한다.
  캐시 만료/삭제가 자동 요청을 유발하지 않는다. 새로고침 버튼으로만 다시 요청한다.
  프로세스 메모리 캐시이며 재시작·용량에 따른 제거 뒤에는 다시 불러와야 한다.

원문 열람은 수집 원장·사용자 파일·진단 ZIP·Chroma에 쓰지 않으며 Runtime.ask/LLM/임베딩을 호출하지 않는다.
미색인 공시는 여전히 원문만 열람한다. 기존 색인에 접수번호·기업코드가 일치하는 공시는 별도 분석 버튼으로 연결한다.

## 화면 이동

- 최신 상세 순서: 기업/제목/날짜 → 본문 불러오기/본문 → 기존 분석 연결 여부 → 공식 원문 → 하단 복귀 버튼.
- 하단 **← 공시 목록으로 돌아가기**는 공시 탐색으로 이동한다. 링크와 버튼 간격은 PC/모바일에서 28px로 검증했다.
- 화면을 벗어나면 Streamlit이 위젯 상태를 정리하므로, 위젯 key에는 `_` 접두사를 쓰고
  필터/범위/페이지는 별도 상태에 보관한다. 최근 목록의 기업·검색·기간·유형·페이지를 복원한다.
  보관 공시 목록 페이지도 별도 상태로 유지한다. chosen_receipt/histories/analyses를 초기화하지 않는다.
- 스크롤은 페이지의 자연스러운 확장을 사용한다. 정확한 픽셀 스크롤 복원은 구현하지 않았다.
  전체 기간 검색의 URL 라우팅·브라우저 방문 기록 지원과 새 세션 복원 범위는
  [disclosure-search.md](disclosure-search.md)를 참고한다. 하단 복귀 버튼도 유지한다.

## 검증

전체 회귀 및 합성 XML/HTML/ZIP·표·빈 본문·오류·미지원·안전한 렌더링·캐시·필터/페이지 복귀를 검증한다.
실제 API 인증정보가 없는 클라우드의 모의 응답 결과를 사용자 로컬의 실제 API 검증으로 간주하지 않는다.
