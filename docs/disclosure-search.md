# 전체 기간 공시 검색

홈은 기존 최근 7일 조회를 유지한다. 공시 탐색의 **전체 기간 검색**은 별도 서비스
`services/disclosure_search.py`에서 기존 `DartClient`의 `list.json` 메타데이터 요청을 재사용한다.
**보관된 공시**, **최근 7일 공시**와 명시적으로 구분한다.

## 검색과 API 제약

- 검색 버튼을 눌러야 새 조건을 적용한다. 기업명/6자리 종목코드는 기존 기업코드 캐시로 해석하며,
  여러 기업이 일치하면 구체적인 이름이나 코드를 요청한다. 8자리 기업코드도 지원한다.
- 기업 미선택은 `corp_code`를 생략하는 전체 기업 검색이다. OpenDART의 3개월 제한을 넘지 않도록
  보수적으로 최대 90일 및 시작일로부터 3개월 미만의 날짜 범위를 허용한다. 긴 기간은 조정 안내한다.
- 특정 기업은 최근 7일 제한 없이 지정 기간을 조회한다. 날짜는 1999년부터 한국 시간 오늘까지,
  공시 유형은 API의 A~J 분류를 사용한다. API가 반환하지 않는 유형은 임의로 추론하지 않는다.
- 일반 검색은 `page_count=20`, `page_no`, `sort=date`, `sort_mth=desc`를 사용한다.
  API 전체 건수와 전체 페이지를 표시한다. 반환 페이지 수가 계산과 다르면 안내하고 API 범위를 따른다.
- API에는 제목 검색 매개변수가 없다. 제목 검색만 최대 1,000건의 메타데이터를 100건씩 제한 조회하여
  제목 부분 일치 결과를 만든다. 이후 페이지는 캐시를 사용한다. 1,000건 초과 또는 도중 결과 변화는
  부분 결과/틀린 총계를 표시하지 않고 기간·기업·유형을 좁히도록 안내한다.
- 성공/빈 결과 5분, 실패 1분 캐시, 최대 128개 항목과 요청 잠금을 사용한다.
  요청 간격은 최소 0.3초다. 운영 계정 전체 호출량 제한은 여전히 적용되며 오류를 빈 결과와 구분한다.
- 본문 다운로드·임베딩·색인·RAG 분석은 검색하지 않는다. 상세의 명시적 본문 요청을 유지한다.
  접수번호와 기업코드가 기존 색인과 모두 일치할 때만 AI 분석으로 연결한다.

## URL과 방문 기록

Streamlit 1.62의 공식 `st.navigation`, `st.switch_page(query_params=...)`,
`st.query_params.from_dict`를 사용한다. `/explore`, `/detail`, `/analysis`, `/history`와 홈 경로를
등록하고 공개 검색 조건·페이지·선택 접수번호를 쿼리에 보존한다. 권한 값은 기록하거나 신뢰하지 않는다.
화면 경로가 기존 `v` 쿼리보다 우선한다. 콜백에서는 이동을 예약하고 다음 실행에서 공식 페이지 전환을 한다.
임의 JavaScript를 사용하지 않는다.

**방문 기록 지원 범위:** Chromium에서 홈→탐색→2페이지 상세→뒤로(탐색2페이지)→앞으로(상세),
새로고침·별도 탭 상세 URL·하단 복귀를 PC/모바일 모두 확인했다.
다만 Streamlit 1.62는 popstate 때 마지막 쿼리를 재사용하는 경우가 있다.
경로가 같은 과거 검색 조건/페이지로의 브라우저 뒤로가기를 완전하게 보장하지 않는다.
과거 상세 여러 건 사이의 이동도 마지막 접수번호가 남을 수 있다. 경로 전환 검증을 전체 history 복원으로 간주하지 않는다.
목록 페이지 버튼 및 하단 복귀는 정확한 조건·페이지를 유지한다.
완전한 조건별 history는 Streamlit의 쿼리 복원 수정 이후 재검증하거나 별도 라우터 프런트엔드를 도입해야 한다.
현재는 한계를 숨기는 JavaScript 우회 구현을 넣지 않았다.

전체 기간 검색의 상세 URL은 새 세션에서도 해당 검색 페이지의 실제 메타데이터를 재조회/캐시 복원한다.
본문은 자동 조회하지 않는다. 원래 기간의 결과가 바뀌어 해당 페이지에 공시가 없으면 복원 불가 안내한다.
최근 7일 상세의 새 세션 복원은 프로세스 최근 조회 캐시에 해당 공시가 있을 때 가능하다.
보관/최근 목록의 세부 필터는 현재 세션에 보존하며, 전체 기간 조건·페이지는 URL에도 보존한다.
대화 기록은 기존과 같이 세션 단위이며 새 세션/서버 재시작 후 영구 복원하지 않는다.
정확한 픽셀 스크롤 위치는 보장하지 않는다.

## 검증과 실행

```bash
.venv/bin/python -m unittest discover -s tests
.venv/bin/streamlit run app.py
```

서비스·AppTest는 모의 응답을 사용한다. 실제 OpenDART 인증정보가 없는 환경에서는
실제 운영 API의 응답 품질/계정 제한 검증으로 간주하지 않는다.

브라우저 회귀(Playwright와 시스템 Chromium 필요, 실제 API 호출 차단):

```bash
.venv/bin/streamlit run tests/search_browser_fixture.py --server.port 8512
# 다른 터미널
.venv/bin/python tests/check_search_browser.py
```

AppTest 1.62는 callable-page hash를 각 실행 사이에 유지하지 않아 단위 테스트에서는
페이지 전환 전송을 대체하고 UI/세션 로직을 검증한다. 실제 페이지 전환은 위 Chromium 회귀로 검증한다.
