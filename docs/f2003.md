# F2003 검색어 추출

`extract_queries(disclosure, question, settings)`는 기존 `Disclosure`, `Settings`를 받는다.
공시 분석 전문가 프롬프트로 메타데이터와 질문을 전달하고 `{"queries":["..."]}`를 반환한다.
문자열 배열·최소 1건·공백 아닌 문자열·추가 필드 금지를 Pydantic으로 검증한다.
검색어는 양끝 공백과 중복을 제거하며, 선택 공시의 14자리 접수번호는 Python 코드에서 반드시 추가한다.
빈 배열은 실패로 처리한다. 선택 공시 원문 다운로드·색인 자체는 F2004/F2005 범위다.

## 설정 및 실행

저장소 루트 `/workspace/dart_insight`에서 기존 가상환경을 사용한다. 추가 패키지는 없다.
기존 `OPENAI_API_KEY` 설정에 **SSAFY GMS 키**를 안전하게 넣는다. 직접 OpenAI 키로 대체하지 않는다.
키는 환경변수·Git에서 제외된 `.env`·전달된 Streamlit Secrets로만 설정하며 채팅에 붙이지 않는다.
기존 `OPENAI_CHAT_MODEL` / `Settings.chat_model`을 그대로 사용한다.
기본값은 `gpt-4.1-mini`이며 실제 GMS 계정의 모델 사용 권한은 별도 확인이 필요하다.
고정 HTTPS 주소 `https://gms.ssafy.io/gmsapi/api.openai.com/v1/chat/completions`로
Bearer 인증을 전송한다. TLS 검증은 유지하고 리다이렉트는 따라가지 않는다.

다음은 실제 F2001 파일에서 선택 공시를 읽어 호출하는 예다. `ACTUAL_COLLECTION_JSON`은
보유한 파일 경로로 바꾼다. 이 명령은 실제 GMS 호출이므로 키·네트워크·실행 승인을 확인한 뒤 실행한다.
일반적인 import, 앱 시작, 단위 테스트에서는 호출되지 않는다.

```bash
.venv/bin/python - <<'PY'
from dataclasses import fields
from pathlib import Path
import json
from dart_insight.config import load_settings
from dart_insight.data.models import Disclosure
from dart_insight.rag.query_extraction import extract_queries

data = json.loads(Path("ACTUAL_COLLECTION_JSON").read_text(encoding="utf-8"))
row = data["disclosures"][0]  # 사용자가 선택한 공시로 대체
selected = Disclosure(**{field.name: row[field.name] for field in fields(Disclosure) if field.name in row})
result = extract_queries(selected, "이 공시의 주요 사업 위험을 찾을 검색어를 추출해 주세요.", load_settings())
print(json.dumps(result, ensure_ascii=False))
PY
```

## 실패 처리 및 검증

- JSON 파싱·스키마·응답 구조 오류: 최초 호출 + 최대 2회 재시도(총 3회).
- 재시도 사이에는 기존 `request_interval_seconds`를 적용한다.
- HTTP 오류·인증/한도·통신 실패: 즉시 안전한 오류로 종료하며 재시도하지 않는다.
- 키 누락·질문 없음·잘못된 선택 접수번호: 호출 전에 실패한다.
- 원본 응답·키·전체 프롬프트를 오류에 출력하거나 재시도 메시지에 복사하지 않는다.
- `session`을 주입할 수 있어 실제 API 없이 요청·응답을 검증할 수 있다.
