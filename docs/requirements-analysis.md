# DART Insight 요구사항 분석·구현 계획

## 검토 기준과 이번 범위

`AI코어프로젝트_2회차_요구사항정의서.pdf` 23쪽 전체를 검토했다.
핵심 기준은 3장 구현 명세(p.11~15), 4장 검증(p.18~19)이며,
2장 기능 표만으로 완료 여부를 판단하지 않는다. 비기능 요구사항과 제출물(p.21~23)도 계획에 포함한다.

사용자 요청에 따라 항목 1건 = **개별 공시 1건**이다. 기업 3개를 3항목으로 계산하지 않는다.
대상은 삼성전자(005930), 현대자동차(005380), 금양(001570)이다.
기업코드는 추측하거나 이름만 매칭하지 않고 OpenDART 공식 기업코드에서 종목코드로 찾는다.

현재 구현: 요구사항 분석, 책임별 패키지 구조, 설정, OpenDART 기업코드·목록 연결,
메타데이터 모델/색인 텍스트 구성, API 응답 캐시, 초기 연결 화면과 F2001 일괄 수집 CLI.
F2001 수집기는 세 기업·유형별 전체 페이지 수집, 과거 기간 확대, 고유 100건 기준 검사,
건수·조회 기간·색인 텍스트를 포함한 로컬 저장을 구현했다. 실제 100건 확보는 미검증이다.
임베딩·원문 다운로드·LLM·LangGraph·채팅은 후속 단계이며 완료로 표시하지 않는다.
빈 패키지는 책임 경계를 표시할 뿐 구현을 의미하지 않는다.

문서에 있는 교육용 영화 도메인 전환 지침이나 제출 사이트 업로드는 실행 명령으로 취급하지 않는다.
현재 사용자가 지정한 DART 도메인·현재 저장소·단계적 작업 범위를 따른다.
F2013~F2016은 심화이며 필수 기능을 대체하지 않는다. 자동 스케줄러·회원가입·주가 예측은 제외한다.

## 도메인 조건

- 확보 목표: 세 기업의 실제 공시 메타데이터 합계 **고유 접수번호 100건 이상**, 기업별 수와 기간 기록.
  날짜·유형별 페이지를 끝까지 조회하고 접수번호로 중복 제거한다. 부족하면 조회 기간을 넓힌다.
  현재 실제 확보 건수는 미확인이다. 실패/빈 응답을 가상 데이터로 대체하지 않는다.
- 외부 문서: OpenDART 공시 원문 ZIP/XML. 필요 원문부터 내려받아 텍스트로 변환한다.
  선택한 공시 자체의 본문은 후보 선별·길이 기준보다 우선하며 반드시 색인한다.
  원문이 없거나 수집 실패 시 미완료·실패를 표시하고 메타데이터만으로 본문을 읽은 것처럼 답하지 않는다.
- 근거가 필요한 질문: “삼성전자의 해당 분기 보고서에 기재된 사업 위험은 무엇인가?”,
  “현대자동차의 이 공시에 나온 자금조달 목적과 조건은 무엇인가?”,
  “금양의 이 정정공시에서 이전 공시와 달라진 수치·조건은 무엇인가?”
  비교 질문은 실제 관련 원문을 모두 확보했을 때만 답한다.
- 금융 면책: “이 서비스는 공시 근거 기반 정보 제공 목적이며 투자 조언이 아닙니다.
  답변은 금융·투자 전문가의 조언을 대신하지 않습니다.”

## 패키지·환경변수

PDF p.5~6의 필수 패키지 14개는 조회 시 모두 PyPI에 해당 버전이 존재했다.
`requirements.txt`에 지정 버전을 그대로 고정했다. XML 외부 엔티티 방어용 `defusedxml==0.7.1`만 추가했다.
심화 전용 FastAPI/Uvicorn/Pydantic 직접 고정은 이번 범위에 포함하지 않는다(전이 의존성과 구별).
전체 해석·설치 검증 결과와 전이 의존성은 `validation.md`, `requirements.lock.txt`를 참조한다.
Python은 명세의 3.10+를 따르되 이번 로컬 검증 버전은 3.12다.

| 설정 | 용도·시점 |
|---|---|
| `DART_API_KEY` | 지금 필요한 OpenDART 키. 채팅·소스에 입력 금지 |
| `OPENAI_API_KEY` | 후속 임베딩/생성 시 필요. 현재 연결 확인에는 불필요 |
| `DART_DATA_DIR` | 기본 `.local/data`, 배포 시 영속성을 보장하지 않는 로컬 경로 |
| `DART_TIMEOUT_SECONDS`, `DART_REQUEST_INTERVAL_SECONDS` | 외부 호출 제한·간격 |
| `DART_CORP_CACHE_TTL_SECONDS`, `DART_LIST_CACHE_TTL_SECONDS` | 기업코드 24시간, 목록 15분. 새 데이터 확인은 refresh |
| `CHUNK_SIZE`, `CHUNK_OVERLAP`, `TOP_K` | 후속 청킹 1000/200, 외부 근거 5개 + 선택 메타데이터 1개 |
| `OPENAI_CHAT_MODEL`, `OPENAI_EMBEDDING_MODEL` | 후속 생성·임베딩 모델. 모델 변경 시 임베딩 컬렉션 재생성 필요 |

우선순위: 프로세스 환경변수 > 전달된 Streamlit Secrets > 저장소 `.env` > 기본값.
CLI는 Secrets 파일을 직접 읽지 않으므로 CLI용 키는 환경변수나 `.env`로 설정한다.
