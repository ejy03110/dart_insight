기존 번호/스키마 검증 뒤에 제한적인 한국어 패턴 검증을 추가했다.
특정 기업·접수번호·할증률을 하드코딩하지 않았으며 청킹·검색 구조는 변경하지 않았다.

- 프롬프트: 제3자배정 대상과 일반 기존 주주의 청약 권리를 구분한다.
  신주 인수자의 의무보유와 기존 보유 주식의 직접 제한을 구분한다.
  공시 사실/해석, 자금 목적의 실제 배정 금액/사용 계획, 정정 전후 조건을 구분하도록 지시한다.
- 검증기: 인식된 기존 주주의 청약·배정 주장에는 인용 원문에서 같은 종류의 명시적 주장을 요구한다.
  특정 기존 주주가 배정대상자로 기재된 사실만으로 일반 청약 권리를 인정하지 않는다.
  기존 주주/기존 주식의 직접 의무보유·매도 제한 주장에도 대응하는 원문 표현을 요구한다.
- 자금 목적: 운영·시설·채무상환·타법인증권취득·영업양수·기타의 인식된 사용 주장에는
  해당 목적의 양수 금액 또는 명시적 사용 문장을 요구한다. 0·대시·없음과 상충하는 인용은 거부한다.
  단순 항목명이나 메타데이터는 충분한 근거가 아니다.
- 주장 바로 뒤의 연속된 `[근거 N]`에 연결된 `opendart_document` 청크만 검사한다.
  다른 검색 청크, 과거 AI 답변, 인용되지 않은 원문으로 주장을 보충하지 않는다.
  마지막 인용 뒤에 남은 인식 가능한 핵심 주장은 별도 인용 없이 통과하지 않는다.
- 실패는 기존 `AnswerValidationError(category=grounding, field=answer, rule=...)`로 처리한다.
  기존 총 호출 예산 안에서만 재시도하며 근거 부족 또는 `supported=false`를 요청한다.
  잘못된 답변을 정상 표시하거나 인용을 만들어 주지 않는다. 로그에는 고정 규칙명만 남긴다.

## 검증하지 못하는 범위

일반적인 의미 함의 검증이나 모든 문장에 대한 사실 검증이 아니다.
한국어 패턴 밖의 표현, 복잡한 부정/이중부정/접속 구조, 정확한 배정대상자 신원·전체/일부 범위,
의무보유 기간·금액·할증률의 정확한 값/산식, 정정 전후의 날짜 우선순위, 미래 주가·사업 성과는
포괄적으로 판정하지 못한다. 사실/해석 구분은 프롬프트 정책이며 모든 문장의 해석 타당성을
자동 보증하지 않는다. 간접적 유통물량 영향도 인과관계를 별도로 검증하지 않는다.
복잡한 표나 생략된 주어는 근거가 있어도 보수적으로 거부될 수 있다.
적용 범위를 벗어난 주장은 기존 인용 검증만 통과할 수도 있으므로 답변의 인용 원문을 확인해야 한다.
