# 최근 7일 공시

홈 또는 공시 탐색의 **최근 공시 불러오기**를 누르면 기존 DART_API_KEY와 DartClient로 조회한다.
단순 화면 이동·검색 입력·상세 열기에는 외부 조회를 하지 않는다. 키가 없으면 조회 실패로 안내하며
보관된 공시 분석에는 영향을 주지 않는다. 기존 환경변수/.env/Streamlit secrets 설정을 재사용한다.

- 기간: 한국 시간 오늘을 포함한 7개 날짜(오늘-6일 ~ 오늘). 주말을 포함한다.
- 대상: 기존 삼성전자·현대자동차·금양. 공식 기업코드에서 종목코드로 기업코드를 찾는다.
- 공시 유형 A~J·전체 페이지 조회, 접수번호 중복 제거, 접수일·접수번호 최신순 정렬.
  원본 공시 제목·기업명·날짜·접수번호·공식 원문 URL을 보존한다.
- 홈 카드에는 최대 3건. 조회 전·성공·결과 없음·조회 실패를 구분한다.
  모든 유형의 조회에 성공하고 자료가 없을 때만 “최근 7일간 새로운 공시가 없습니다.”라고 표시한다.
  일부 유형만 실패해도 그 기업을 성공/없음으로 표시하지 않는다.
- 성공/빈 결과는 5분간 프로세스 메모리에 보관하며, 동시 새로고침을 직렬화·병합한다.
  실패는 1분간 재시도 대기. 캐시 만료가 자동 조회를 유발하지 않으며 버튼을 다시 눌러야 갱신한다.
  조회 시각을 표시하고 날짜가 바뀌면 새 기간을 조회하기 전까지 미조회 상태로 표시한다.
- 새로고침 시 만료된 최근 목록만 실제 조회하며, 기업코드는 기존 장기 캐시를 재사용한다.
  기존 클라이언트의 성공 응답 디스크 캐시·TLS·timeout·제한 재시도는 유지한다.
  최근 조회가 쓰는 메모리 캐시는 서버 재시작 시 사라진다. 재시작 후 명시적 조회는 다시 요청한다.
- 처음 전체 조회는 최소 기업별 10개 유형(총 30개 목록 요청) + 기업코드 조회이며 추가 페이지가 있으면 늘어난다.
  클라이언트 간격은 최소 0.3초, 설정이 더 길면 그 값을 따른다. 인증/요청 한도 오류는 남은 기업 조회도 중단한다.
  이 조정은 최근 조회 클라이언트에만 적용하고 기존 RAG 설정/동작은 바꾸지 않는다.

공시 탐색에서 **보관된 공시 / 최근 7일 공시**를 구분한다. 최신 공시는 원문·상세를 열 수 있다.
현재 메타데이터 색인의 접수번호와 기업코드가 모두 일치하면 **기존 공시 분석 열기**로 연결한다.
미색인 공시는 공식 원문 확인만 가능하며 자동 색인·임베딩·분석 준비를 수행하지 않는다.
“AI 분석 가능”은 기존 메타데이터 연결을 의미하며 실제 분석에는 기존 DART/GMS 등 실행 설정이 필요하다.

관리자 인증 및 RAG/Chroma/임베딩/검증/멀티턴 로직은 그대로다. 조회 캐시 외 사용자 DB/색인을 변경하지 않는다.
실제 외부 API 검증은 인증정보가 제공된 환경에서 별도로 수행해야 한다. 테스트의 합성 공시는 운영에 사용하지 않는다.
